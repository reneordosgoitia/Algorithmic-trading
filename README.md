## 📊 Volatility K-Means Clustering

My latest script demonstrates how to:

1. **Fetch** BTCUSDT & ETHUSDT 15-minute data in parallel  
2. **Compute** log-returns and rolling mean/standard-deviation windows  
3. **Cluster** with a 3-cluster K-Means on volatility vs. mean return  
4. **Visualize** side-by-side scatter plots of each asset’s clusters
